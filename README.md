# 🔥 Высокоскоростной парсер Wildberries (API)

**Статус:** Production-ready (Готов к коммерческому использованию)
**Стек:** Python 3.11, requests, pandas, openpyxl, tenacity, fake-useragent

## 💡 Описание проекта
Асинхронный Python-скрипт для высокоскоростного сбора данных о товарах с маркетплейса Wildberries. 
В отличие от хрупких парсеров на Selenium, данный скрипт обращается напрямую к **скрытому внутреннему JSON API Wildberries**, что обеспечивает максимальную скорость и стабильность.

## ⚙️ Основной функционал
- Сбор данных по поисковому запросу или ID категории.
- Извлечение коммерческих метрик: Артикул, Бренд, Название, Цена, Рейтинг, Отзывы, Остатки.
- **Антибан система:** Динамические задержки, ротация User-Agent, автоматические повторные попытки (retry) при сбоях серверов.
- Автоматический экспорт собранных данных в готовый `.xlsx` (Excel) отчет.

## 🚀 Преимущества для бизнеса
Скорость сбора данных возрастает в 50 раз по сравнению с ручным трудом или браузерной автоматизацией. Идеально подходит для селлеров, анализирующих цены конкурентов и остатки на складах. 0 блокировок благодаря грамотному rate-limit.
